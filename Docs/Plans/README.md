# Plan documents

Copies of the Claude documents this project was planned in, taken on 18 November 2026 so that the repository
holds them. The live version of each is the Claude document it links to: that is where progress notes are added.
Take a fresh copy when a plan changes a lot (ask Claude to "refresh Docs/Plans"). Pictures and embedded charts are
not in the copies.

Read the one for the work in hand. Do not read them all: together they are about 900 KB.
